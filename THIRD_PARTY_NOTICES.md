## SmoothUI

The Glass theme rebuilds these SmoothUI components in plain CSS and JavaScript (the
originals are React + Framer Motion): Glass Card, Tilt, Number Flow, Toast, Border Beam,
Tabs, Stepper, Mac Terminal, Progressive Blur, Dynamic Island and Power Off Slide.

Files: `server/static/cronrack/css/glass.css`, `server/static/cronrack/js/glass.js`,
`server/static/cronrack/js/glass-tabs.js`, `server/static/cronrack/js/power-slide.js`.

Source: https://github.com/educlopez/smoothui
