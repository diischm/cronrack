{# PLACEHOLDER — Apo owns the final version #} {% comment %} Confirm dialog (handoff 5.6), used by js/dialog.js. Include it ONCE on a page that has forms marked class="js-confirm", and load dialog.js. The forms work without JavaScript: each one has its own visible confirmation (a "Yes, ..." checkbox or a typed-name field, inside an element with class="js-confirm-nojs") that the server checks. With JavaScript, dialog.js hides those, catches the submit, opens this dialog and fills it from VISIBLE text in the form (textContent only, never data- attributes): title the form's .js-confirm-title sentence the form's .js-confirm-text action the form's submit key label (red text: every use is destructive) name the form's .js-confirm-name, if the form has a typed-name field: the dialog then asks for it, and the action key stays aria-disabled until it matches Confirm ticks the checkbox / copies the typed name into the form, then submits it. The server decides either way; the check here is only so the user can't miss it. Focus goes to Cancel (never the destructive key), Tab stays inside, Esc / Cancel / a click on the backdrop close it, and focus returns to the key that opened it. Without JS this markup is never opened, so it stays empty and hidden. {% endcomment %}
