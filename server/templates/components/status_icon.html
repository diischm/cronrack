{# PLACEHOLDER — Apo owns the final version #}{% comment %} A status as an icon whose SHAPE differs per status, so it is never colour-only. Usage: {% include "components/status_icon.html" with status=host.status label=host.status_label %} status red | yellow | green | info | waiting | example | maintenance anything else (offline, empty) renders nothing: an offline host has its unlit lamp + "Offline · last report …" text instead. label the words (optional; default per status: Needs you, Heads up, All good, Info, Waiting, Example) red: alert triangle, yellow: exclamation in a circle, green: check in a circle, info / example / maintenance: "i" in a circle (muted), waiting: hourglass (muted). The SVG is decorative (aria-hidden); the words sit right next to it, visually hidden, so screen readers and a parent link's accessible name get them ("nas, All good, …"). title= shows them on mouse hover.
