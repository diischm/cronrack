Usage: {% include "components/password_field.html" with field=form.old_password label="Current password" autocomplete="current-password" %} The input is written out here (not {{ field }}) so the page decides two things itself: the autocomplete value (current-password / new-password) and focus. Django's PasswordChangeForm puts autofocus on the current password, which would grab focus on every visit to Settings; here only a field with an error gets it. A password is never written back into the page. The key is a toggle: aria-pressed says whether the password is shown, its name stays "Show password". It does nothing without JavaScript, so it starts hidden; password.js shows it. {% endcomment %}
